# 🛠️ Python Utility Tools

**Simple, practical Python tools for everyday tasks.**

This repository contains small Python projects built to solve everyday problems, practice programming concepts, and improve problem-solving skills.

---

## 📌 Projects

### 01 — Text Analyzer

A command-line tool that analyzes text and provides useful statistics.

**Features**

- Character, letter, and digit counting
- Number detection and extraction
- Word and unique word counting
- Longest and shortest word detection
- Average word length calculation
- Most frequently used words
- Estimated reading time
- Multiple text analysis in one session

---

## 🚀 Getting Started

### Requirements

- Python 3.x

No external libraries are required.

### Installation

Clone the repository:

```bash
git clone https://github.com/erimkrkl/python-utility-tools.git
```

Navigate to the project folder:

```bash
cd python-utility-tools
```

### Run the Text Analyzer

**Version 1**

```bash
python text_analyzer.py
```

**Version 2**

```bash
python text_analyzer_v2.py
```
